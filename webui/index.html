Before You Start

The AIOC must already be in DFU (bootloader) mode before it will show up here — this tab does not switch it for you. See the AIOC hardware docs for how to enter DFU mode on your firmware version, then click Connect above and select the device (same USB ID as normal use, 1209:7388, unless you've overridden it).

⚠ Only flash official AIOC firmware images built for this hardware. The device's boot ROM is separate from application flash, so a failed flash is recoverable via the manual DFU-entry procedure — but a wrong or corrupt file can still leave the AIOC needing that recovery step.
